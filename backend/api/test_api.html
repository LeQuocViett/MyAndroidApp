🚀 DNCS3 API - Test Tool

Công cụ kiểm tra API Quản Lý Người Dùng

1️⃣ Lấy Tất Cả Users

GET/get_users.php

2️⃣ Cập Nhật User

POST/update_user.php
Request Body: 
{
  "id": 1,
  "name": "Nguyễn Văn A",
  "email": "a@example.com",
  "phone": "0901234567",
  "status": "ACTIVE"
}

3️⃣ Khóa Tài Khoản

POST/block_user.php
Request Body: 
{
  "id": 1
}

4️⃣ Mở Khóa Tài Khoản

POST/unblock_user.php
Request Body: 
{
  "id": 1
}

5️⃣ Xóa User (Soft Delete)

POST/delete_user.php
Request Body: 
{
  "id": 1
}

6️⃣ Tìm Kiếm Users

GET/search_users.php?query=nguyễn&searchType=name

💡 Tip: Mở Developer Console (F12) để xem chi tiết response
